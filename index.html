The spec: keys in, frames out

Not given: where games run, the API, which games. Soft constraint: prefer games in our training data.

Constraints

011,000 machines at once
02Deterministic: 50 ms means 50 ms
03Start mid-game, not at the menu
04Metrics, not just pixels
Why determinism: the model trained on smooth 20 FPS footage, so no train/test shift. Latency-insensitive, so you can batch and eval slow models. Same inputs give the same result: lower variance, and you can branch evals from hard moments.

Options

Windows GPUs, stream videocan't freeze time
Pause / resume the VM50 ms becomes 67 ms
GPU snapshotsdon't exist for graphics
Firecracker snapshots, on CPU✓ chosen
Also rejected: booting and scripting each game to the start point on every eval (slow and flaky at 3k/day). Cloud Hypervisor has GPU support, but GPU snapshotting only exists for CUDA (Modal), not gaming. Chosen: Linux + Proton + llvmpipe. Cost: CPU rendering ~6x slower than real time; only DRM-free single-player games (GOG).

The hard part

Ask for 50 ms.
Get 66.7 ms.

Slow CPU frames make the engine run catch-up physics ticks

Tried hooking the game clock (QPC) with a time-scaling library. A 33 ms frame makes the engine run 2 ticks of 16.7 ms, so 50 ms asked becomes 66.7 ms: 4/3 too fast. Some games read the timer directly and skip QPC entirely. Show the Excalidraw fake-clock table if they want depth.

Fix: reverse-engineer
every game loop

LLM + Ghidra, pin 1 frame = 1 physics tick

Scaffolding: decompile, write its own tests, spin up sandboxes repeatedly until it passes the verification protocol. Start positions are codified as workflow files (the LLM drives menus with a VLM), so snapshots are reproducible to 0.02% and can be rebuilt on another vendor.

Verify it

×100Same inputs, identical output
=One 100 ms step = two 50 ms steps

Caught: 25% of runs dropped the first key press

Also stitch frames into a video by logical time and check it looks like training data. The dropped keypress was a race on snapshot resume; the fix was a delay. Once the protocol was solid, the LLM's job became "make this game pass."
